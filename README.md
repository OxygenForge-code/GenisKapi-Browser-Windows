# GenişKapı Browser Windows

Modern Chromium-based Windows browser by OxygenForge.

## 0.4.0 feature foundation
The repository now contains modular foundations for tabs, history, bookmarks, downloads, settings, sessions, extensions, privacy, navigation, commands, notifications and performance monitoring.

## Build
Run `powershell -ExecutionPolicy Bypass -File BUILD-WINDOWS.ps1` on Windows.

## Status
Early development. The modules are being integrated incrementally into the browser shell.
