# GenişKapı Browser Windows

A modern Chromium-based Windows browser project by OxygenForge.

## Features
- Chromium-powered browsing via Electron
- Tabs and new-tab workflow
- Back / forward / reload / home navigation
- Secure Electron defaults
- Basic tracker/ad blocking
- Bookmarks and browser history UI foundation
- Portable Windows build workflow
- Modern GenişKapı visual identity

## Build
Run `powershell -ExecutionPolicy Bypass -File BUILD-WINDOWS.ps1` on Windows.

The script installs dependencies and produces a portable Windows executable.

## Status
Early development — the project is being actively expanded toward a full-featured browser.
